機械要素・金型

歯車・ボールねじのように機械の中で力と動きを伝える「機械要素」と、部品を正確につくるための治具・金型・成形ロール。どれも自動車や産業機械の性能を裏で決める部品で、μm単位の精度と、熱処理・研削・測定の技術が集まる。

業界の構造

  • 歯車: 自動車・建設機械・産業用減速機・ロボット向けの中小形歯車は専門メーカーや自動車部品メーカーが量産し、製鉄・セメント・船舶・風力向けの大型歯車は重工・歯車専業メーカーが1台ずつ受注生産する。
  • ボールねじ: 工作機械・射出成形機・半導体製造装置・ロボット・電動アクチュエータの送り軸に使われる。精密な研削ボールねじと、量産向けの転造ボールねじがあり、軸受メーカーや専業メーカーがつくる。
  • 治具・金型: 部品メーカーの社内の金型工場（ツールルーム）と、専門の治具・金型メーカーがつくる。1型・1台ごとの受注生産で、設計から試し打ちまで数週間〜数か月かかる。
  • フォーミングロール: ロール成形機で帯鋼を少しずつ曲げて、建材・自動車の骨格部材・レール・パイプをつくるための成形ロール。成形機メーカーやロール専業メーカーが、製品の断面ごとに1セットずつ設計・製作する。

つくり方の特徴

  • 量産と一品物が混在する: 同じ歯車でも、月に数万個つくる量産品と、直径数mを1個だけつくる一品物では、設備・工具・品質の保証の仕方がまったく違う。
  • 焼入れしてから仕上げる: 歯車・ボールねじ・金型・ロールはどれも、硬くするための熱処理の後に、研削や放電加工で最終の形と寸法を出す。熱処理ひずみをどう見込むかが腕の見せどころになる。
  • 測定が品質そのもの: 歯車の歯形、ボールねじのリード、金型の穴位置は、専用の測定機で測って初めて品質が保証できる。測定機の能力が、つくれる精度の上限を決める。
  • 設計と製造が近い: 治具・金型・ロールは、製品の図面から型の形を設計するところから始まる。設計の良し悪しが、試し打ちの回数と製品の品質に直結する。

必要とされる工作機械・設備

  • ホブ盤: 歯車の歯を削り出す。
  • 歯車研削盤: 焼入れ後の歯面を仕上げ、精度と静かさを出す。
  • ねじ研削盤: ボールねじのねじ溝をリード精度μm単位で研削する。
  • ジグ研削盤: 焼入れした治具・金型の穴を、位置・径ともにμm単位で仕上げる。
  • 成形研削盤: パンチやロールの複雑な輪郭を研削で仕上げる。
  • 放電加工機: 焼入れ鋼や超硬の金型の穴・輪郭を切り抜く。
  • 歯車測定機: 精度を数字で保証する。
