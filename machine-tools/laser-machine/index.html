レーザ加工機

レーザ加工機とは、レーザ光をレンズや鏡で小さな点に集め、その高いエネルギーで材料を溶かしたり蒸発させたりして、切断・溶接・穴あけ・マーキングなどを非接触で行う工作機械である。

  2. 2

  3. 3

構造と仕組み

主な構成は、レーザ光をつくる発振器、光を運ぶ伝送系、光を集めて加工点に当てる加工ヘッド、ヘッドと工作物を動かす駆動部である。金属加工では、光ファイバで光を運べるファイバレーザが広く使われ、二酸化炭素を使うCO2レーザは鏡で光を運ぶ。両者は波長が異なり、ファイバレーザの光は金属に吸収されやすく、CO2レーザの光は樹脂や木材などにもよく吸収される。

切断では、加工ヘッドのノズルからアシストガスを吹き付け、溶けた金属を下へ吹き飛ばす。軟鋼には酸素を使って燃焼の熱も利用し、ステンレスやアルミには窒素を使って切り口の酸化を防ぐ。ヘッドはセンサで板の表面との距離を一定に保ち、焦点の位置を合わせ続ける。

平板を切る2D加工機は、ヘッドを載せた門形の構造をリニアモータやサーボモータでX・Y方向に高速で動かす。立体的な部品を加工する3D加工機は、ヘッドに旋回軸を持たせた5軸構成やロボットで、ヘッドの向きを変える。溶接やマーキングでは、ガルバノスキャナ（モータで角度を変える鏡）で光を高速に振り、機械を大きく動かさずに加工点を移す。レーザ光は目や皮膚に危険なため、加工範囲を遮光カバーで囲み、煙や粉じんは集じん機で吸い取る。

得意な加工と自動車部品での例

レーザ加工機は、工具を当てずに細かい形状を速く切ることと、熱が入る範囲を狭くして溶接することが得意である。3Dレーザ加工機は、熱間プレス（ホットスタンプ）で硬くした車体骨格部品の穴あけや縁切りに使われ、硬すぎて抜き型では加工しにくい部品に向く。レーザ溶接では、デフケースに最終減速用の大歯車を溶接し、ボルトによる締結を減らす使い方がある。変速機ギヤでも、歯車と別の部品を溶接で一体化する例がある。燃料噴射インジェクタ（直噴）では、部品どうしを封止する溶接に使われる。マーキングでは、シリンダーブロックやシリンダーヘッドに製造番号や2次元コードを刻み、工程の記録をたどれるようにする。プレス金型では、摩耗した刃先の肉盛補修や表面の焼入れに使う。電気を通す材料しか加工できない放電加工機と違い、樹脂なども加工できる。

選ぶときのポイント

  • 切断・溶接・マーキングのどれが主な目的かで、発振器の種類と出力、加工ヘッドが変わる。
  • 材料と板厚の範囲を整理し、切り口や溶け込みの品質を試し加工で確認する。
  • 3D加工では、部品ごとの治具と、ヘッドの動きをつくるプログラム作成の手間を見込む。
  • アシストガス、電力、ノズルやレンズ保護ガラスなどの運転費用を見込む。
  • 遮光、排気・集じんなど、安全と環境の設備を合わせて計画する。

自動化との組み合わせ

2D切断では、材料棚から板を自動で積み込み、切った部品を仕分けて積み上げる装置と組み合わせ、夜間も連続で運転する。溶接やマーキングはロボットや搬送ラインと組み合わせやすく、カメラやセンサで溶け込みを監視したり、刻んだ2次元コードを読み取って次の工程に情報を渡したりする。

02使い方の流れ

電源を入れてから1個目を仕上げ、量産に移るまでの標準的な流れ。実際の手順と数値は、機械の取扱説明書と社内の作業標準に従う。

  1. 起動の確認

    冷却装置（チラー）とガスの圧力を確認する。

  2. ノズルと保護ガラスの点検

    ノズルの傷と汚れ、レンズを守る保護ガラスの汚れを確認する。

  3. ノズルの芯出し

    レーザ光がノズルの真ん中を通るように合わせる。

  4. 焦点位置の確認

    材料と板厚に合った焦点位置になっているかを確かめる。

  5. 材料の載せ方

    材料の表裏と保護フィルムの向きを確認して載せる。

  6. 条件の呼び出しと試し切り

    材質と板厚の条件を呼び出し、裏側の溶けかす（ドロス）や切断面を確認する。

  7. 加工と製品の取出し

    加工後、製品と残った枠（スケルトン）を分ける。

03知っておくべきこと

削る・磨くといった主な機能の陰で、仕上がりと安全を左右する作業や現象がある。トラブルの多くはここから起きる。

焦点とノズルの芯

焦点がずれたりノズルの芯が外れたりすると、切れない、溶けかすが付く、切断面が荒れる。加工不良のときはまずここを確認する。

保護ガラスの汚れ

汚れたままだと出力が下がり、さらにガラスやレンズが焼ける。始業時に必ず点検する。

アシストガスの使い分け

酸素は鉄と反応して熱を足すため厚い鋼板を速く切れるが、切断面に酸化膜が残る。窒素は酸化させずに切れるため、ステンレスやアルミ、溶接や塗装をする部品に使う。

反射しやすい材料

銅やアルミはレーザ光をはね返しやすく、戻った光が機械を傷めることがある。対応した機種と条件を使う。

小さな部品の跳ね上がり

切り終わった小部品が傾いて跳ね上がり、ノズルに当たることがある。小さな切り残し（ジョイント）で枠につないでおく。

安全

レーザ光は目に見えにくく、反射光でも目を傷める。保護囲いを開けたまま運転せず、ヒュームの排気と火災に注意する。

04想定問答

仕様の打ち合わせで、お客様から実際によく聞かれる質問と、その答え方の例。数値をその場で約束せず、条件を確かめてから根拠とともに答えるのが基本である。

Q何mmの板まで切れますか。

A出力と材質、アシストガスで決まります。よく切る板厚と、たまに切る最大の板厚をお聞きして、必要な出力を選びます。

確認のポイント最大板厚に合わせると過剰な投資になることがある。

Q窒素と酸素、どちらのガスを使えばいいですか。

A厚い鋼板を速く切るなら酸素、ステンレス・アルミや、溶接・塗装をする部品で酸化膜を嫌うなら窒素です。窒素は使用量が多いため、供給方法（液体窒素、窒素発生装置）とガス代の試算もお出しします。

確認のポイントガス代は運用費の大きな部分。具体的に試算する。

QファイバレーザとCO2レーザ、どちらがいいですか。

A薄板〜中厚板の金属切断では、加工速度と電気の効率でファイバレーザが主流です。材料と板厚の構成をお聞きして判断します。

確認のポイント銅・アルミなど反射しやすい材料の扱いも確認する。

Q材料の出し入れを自動にできますか。

A材料の自動供給、製品の取り出し・仕分け、材料のストッカを組み合わせて、夜間の連続運転ができます。

確認のポイント製品の仕分けが手作業のままだと、自動化の効果が限られる。

Q安全対策はどうなっていますか。

Aレーザ光を遮る囲いとインターロック、集じん・排気の設備が必要です。社内のレーザ安全管理の体制づくりもご説明します。

確認のポイントヒュームの排気と火災対策も必ず伝える。

どの機械でも聞かれること

Q納期と、立ち上がるまでの期間はどのくらいですか。

A機械本体の納期に加えて、据付け・試運転・初品確認・量産立上げまでを工程表にしてお出しします。御社のワーク・治具・自動化を含めた形でお約束できる日程を、仕様が固まった時点で確定させてください。

確認のポイント機械単体の納期だけを答えると、治具・ローダ・プログラムの準備で立上げが遅れたときに食い違う。検収条件（何個連続で、どの寸法がCpk何以上か）を同時に決めておく。

Q故障したとき、どのくらいで来てもらえますか。部品はありますか。

Aサービス拠点からの出動の目安と、主軸・NC・サーボなど止まると困る部品の在庫・取り寄せ期間をメーカーに確認してお答えします。止められない設備でしたら、予備品として持っておくべき部品の一覧もご提案します。

確認のポイント「すぐ行きます」とは言わない。夜間・休日の対応範囲、リモート診断の有無、保証期間と保証の対象外（消耗品・誤操作）を文書で示す。

Qオペレータや保全の教育はしてもらえますか。

A操作・プログラム・日常点検・定期保全の教育内容と日数、場所（メーカーの研修施設か御社か）をご提示します。立上げ時に誰が何を担当するかも一緒に決めましょう。

確認のポイント教育の範囲が曖昧だと、引き渡し後の問い合わせが増える。操作説明書・保全マニュアル・電気図面の提出範囲も確認する。
