ホブ盤

ホブ盤とは、ねじ状に切れ刃が並んだ工具（ホブ）と工作物を、かみ合う歯車のように一定の比率で同期回転させながら送り、外歯の平歯車やはすば歯車、スプラインの歯を連続して削り出す工作機械である。

構造と仕組み

ホブは、ねじの山に溝を入れて多数の切れ刃をつくった工具で、切れ刃の断面は歯車とかみ合う直線状の歯（ラック）の形をしている。ホブを1回転させるごとに工作物を「ホブの条数（ねじ山の本数）÷工作物の歯数」回転させると、切れ刃の通り道が重なってインボリュート歯形（歯車のかみ合いに使う曲線）ができる。工具の動きの重ね合わせで形をつくるこの方法を創成という。

主な軸は、ホブを回すホブ主軸、工作物を載せて回すテーブル（C軸）、切込みを与える径方向のX軸、ホブを歯幅方向に送るZ軸、ホブの傾きを合わせる旋回軸（A軸）である。はすば歯車では、Z軸の送りに合わせてテーブルに追加の回転を与え、ねじれた歯すじをつくる。現在の機械は、この同期を換え歯車ではなく、NC装置とサーボモータによる電子的な同期で行う。

ホブは同じ位置ばかり使うと一部の刃だけが摩耗するため、接線方向にずらすホブシフト（Y軸）で使う刃を少しずつ変える。切削点でホブの刃が動く向きと送りの向きをそろえるクライム切りは、工具の摩耗が少なく、量産で多く使われる。切削油を使わないドライカットも広く使われ、切りくずを素早く外へ出す構造と、機械の熱変位への対策が重要になる。

得意な加工と自動車部品での例

ホブ盤は、外歯の歯車を短いサイクルで連続して削るのが得意で、歯車加工で最も広く使われる。自動車では、変速機ギヤやe-Axle減速機ギヤの歯を熱処理前に削り、変速機シャフトと一体になった歯車やスプラインも加工する。熱処理後は歯車研削盤やホーニングで歯面を仕上げるのが代表的な流れで、熱処理前にシェービングで歯面を整える場合もある。ホブは工作物の外側からしか削れないため、内歯車はギヤスカイビング盤や歯車形削り盤、ブローチ盤で加工する。ディファレンシャルギヤ（ハイポイド）のような傘歯車も、ホブ盤ではなく専用の歯切り盤で削る。

選ぶときのポイント

  • 対象歯車の外径、モジュール、ねじれ角、歯幅を整理し、機械の範囲に収まるかを確認する。
  • 段付き軸では、隣の段とホブが干渉しないか（ホブの逃げ）を図面で確かめる。
  • ドライカットにするなら、切りくずの排出と熱変位への対策を確認する。
  • 面取り・バリ取りを同じ機械で行うかどうかで、工程数とラインの長さが変わる。
  • 段取り替えが多いなら、ホブと治具の交換にかかる時間を比べる。

自動化との組み合わせ

量産では、2つの工作物台を旋回させて入れ替える旋回式ローダやガントリーローダで、加工中に次の工作物を待機させ、出し入れの時間を短くする。歯車は前工程の旋削、後工程の面取り・シェービング・熱処理とつながるため、搬送コンベヤでラインとして組むのが一般的である。ホブの摩耗は加工数で管理し、シフトや交換の時期をNC装置が知らせる。

02使い方の流れ

電源を入れてから1個目を仕上げ、量産に移るまでの標準的な流れ。実際の手順と数値は、機械の取扱説明書と社内の作業標準に従う。

  1. 暖機運転

    ホブ軸とテーブルを回して温度を安定させる。

  2. ホブの取付け

    ホブアーバに付け、振れを確認する。

  3. ホブの芯出し

    ホブの刃の山を工作物の中心に合わせる。

  4. 工作物の取付け

    アーバや治具で固定し、振れを確認する。

  5. 条件の入力

    歯数、モジュール、ねじれ角、送りなどを入力する。

  6. 試し加工と測定

    オーバーピン寸法（歯溝にピンを入れて測る寸法）やまたぎ歯厚で歯の厚さを測る。

  7. 補正と量産

    歯厚の結果から切込みを補正し、量産に入る。

03知っておくべきこと

削る・磨くといった主な機能の陰で、仕上がりと安全を左右する作業や現象がある。トラブルの多くはここから起きる。

ホブの振れと芯出し

ホブの振れや芯のずれは、歯形の誤差として歯車に写る。取付けのたびに確認する。

ホブシフト

同じ刃ばかり使うと一部だけ早く減る。ホブを少しずつ軸方向にずらして全体を均等に使い、寿命を延ばす。

歯厚の管理

かみ合いのすき間は歯厚で決まる。オーバーピン寸法で管理し、ホブが減った分を補正する。

再研削後の補正

ホブを研ぎ直すと外径が小さくなるため、切込みの設定を合わせ直す。

乾式の熱

乾式では熱がワークと機械に残りやすい。切りくずの排出と温度変化に注意する。

04想定問答

仕様の打ち合わせで、お客様から実際によく聞かれる質問と、その答え方の例。数値をその場で約束せず、条件を確かめてから根拠とともに答えるのが基本である。

Qドライ（切削油なし）で削れますか。

A超硬ホブとコーティングを使えば乾式で削れ、油の管理と洗浄の手間が減ります。熱がワークと機械に残りやすいため、切りくずの排出と温度の管理も合わせてご提案します。

確認のポイント乾式は工具費と機械の対応が必要。今の工具で可能かも確認する。

Qホブは何本・どんな仕様が必要ですか。

A歯車の諸元ごとにホブが必要です。品種数と生産量から、ホブの材質・条数・本数と再研削のサイクルを試算します。

確認のポイント工具費は運用費の大きな部分。研ぎ直しの体制も聞く。

Q歯切りと同時に面取りできますか。

A面取り装置を内蔵した機種なら、歯切りと並行してバリ取り・面取りができ、別工程を減らせます。

確認のポイント面取りの形状の要求を確認する。

Q段取り替えにどのくらいかかりますか。

Aホブ・治具・プログラムの交換と、ホブの芯出しの時間です。自動ホブ交換やクイックチェンジ治具で短縮できます。

確認のポイント品種の切替え頻度を聞いて、必要な機能を絞る。

Q精度はどの等級まで出ますか。

Aホブ切りで出せる精度と、後工程（シェービング・研削）で仕上げる前提の精度を分けてお答えします。後工程の取り代も合わせて決めましょう。

確認のポイントホブ切りだけで最終精度を狙うのか、後工程ありかで機械の選び方が変わる。

どの機械でも聞かれること

Q納期と、立ち上がるまでの期間はどのくらいですか。

A機械本体の納期に加えて、据付け・試運転・初品確認・量産立上げまでを工程表にしてお出しします。御社のワーク・治具・自動化を含めた形でお約束できる日程を、仕様が固まった時点で確定させてください。

確認のポイント機械単体の納期だけを答えると、治具・ローダ・プログラムの準備で立上げが遅れたときに食い違う。検収条件（何個連続で、どの寸法がCpk何以上か）を同時に決めておく。

Q故障したとき、どのくらいで来てもらえますか。部品はありますか。

Aサービス拠点からの出動の目安と、主軸・NC・サーボなど止まると困る部品の在庫・取り寄せ期間をメーカーに確認してお答えします。止められない設備でしたら、予備品として持っておくべき部品の一覧もご提案します。

確認のポイント「すぐ行きます」とは言わない。夜間・休日の対応範囲、リモート診断の有無、保証期間と保証の対象外（消耗品・誤操作）を文書で示す。

Qオペレータや保全の教育はしてもらえますか。

A操作・プログラム・日常点検・定期保全の教育内容と日数、場所（メーカーの研修施設か御社か）をご提示します。立上げ時に誰が何を担当するかも一緒に決めましょう。

確認のポイント教育の範囲が曖昧だと、引き渡し後の問い合わせが増える。操作説明書・保全マニュアル・電気図面の提出範囲も確認する。
