主軸台とは

しゅじくだいHeadstock

旋盤や円筒研削盤で、工作物を回す主軸を収めた箱形の部分。

主軸台の仕組みと実務のポイント

反対側の心押台と向かい合って工作物を支える。

研削盤の主軸台はセンタを回さない「死センタ」方式を選べる機種があり、主軸軸受の振れが工作物に写らないため、真円度の高い仕上げに使われる。

関連する用語

  • 主軸工具や工作物を回す、機械の心臓にあたる回転軸。
  • 心押台主軸の反対側から、長い工作物の端をセンタで押さえて支える台。
