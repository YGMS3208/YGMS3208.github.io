歯車研削盤

歯車研削盤とは、熱処理で硬くなった歯車の歯面を砥石で削り、熱処理ひずみや歯形・歯すじ・ピッチの誤差を取り除いて、高い精度で静かにかみ合う歯車に仕上げる工作機械である。

構造と仕組み

量産で主流の連続創成研削は、ホブ盤と同じ原理で動く。ホブの代わりに、外周にねじ山をつけた円筒状の砥石（ねじ状砥石）を使い、砥石を回す主軸と工作物を載せたC軸を、歯車がかみ合う比率で電子的に同期させる。ねじ山の側面が次々と歯面に当たり、径方向のX軸で切込みを与え、歯幅方向のZ軸で送って歯面全体を削る。

加工の前に、熱処理前に削られた歯の位置をセンサで検出し、ねじ山を歯溝に合わせる「かみ合わせ（位相合わせ）」を自動で行う。砥石の形は、ダイヤモンドを付けた回転工具（ドレッサ）でねじ山をなぞって整える。このときドレッサの動きを変えると、歯先を少し落とす歯先修整や、歯幅の中央をふくらませるクラウニングなど、狙った歯形修整を砥石に写せる。砥石は軸方向にずらして（シフトして）新しい部分を使う。

もう一つの方式である成形研削は、歯溝の断面と同じ形にドレスした円板砥石で1つの歯溝を削っては、工作物を1歯分割り出す。連続創成研削より時間はかかるが、歯形修整の自由度が高く、大径の歯車、段が近くてねじ状砥石が入らない歯車、内歯車にも対応しやすい。

研削の熱で歯面の硬さが落ちる「研削焼け」を防ぐため、クーラントの量や切込みを管理し、仕上がった歯形と歯すじを機上や測定機で確認する。

得意な加工と自動車部品での例

歯車研削盤は、熱処理で生じたひずみを取り、歯車の騒音（ギヤノイズ）の原因となるかみ合いの誤差を小さくするのが得意である。自動車では、多段の変速機ギヤや、変速機シャフトと一体になった歯車を連続創成研削で仕上げる。電動車のe-Axle減速機ギヤは、モータの高い回転数で回り、エンジン音にかき消されないため静粛性の要求が特に厳しく、研削やポリッシュでの仕上げが重視される。ホブ盤で歯を削り、熱処理後に歯車研削盤で仕上げるのが代表的な工程の流れである。ディファレンシャルギヤ（ハイポイド）は傘歯車用の専用研削盤や、かみ合わせて磨くラッピングで仕上げるもので、この機種とは別である。

選ぶときのポイント

  • 生産量と歯車の形（外歯か内歯か、軸付きか、段との干渉）から、連続創成研削か成形研削かを決める。
  • 必要な精度等級と歯形修整の種類を整理し、ドレス方式で再現できるかを確認する。
  • 熱処理前の歯に残す取り代と、自動かみ合わせの精度を確認する。
  • ねじ状砥石の交換とドレスにかかる時間、砥石1本で研削できる数を見積もる。
  • 研削焼けを防ぐクーラント設備と、焼けの検査方法を合わせて考える。

自動化との組み合わせ

量産機は、旋回式ローダやガントリーローダで加工中に次の工作物を準備し、出し入れの時間を短くする。研削後の歯形を測定機で測り、その結果をドレスの動きに戻して歯形を補正する仕組みを組み合わせる。一定数ごとに抜き取って研削焼けを検査する工程ともつなぎ、ライン全体で品質を保つ。

02使い方の流れ

電源を入れてから1個目を仕上げ、量産に移るまでの標準的な流れ。実際の手順と数値は、機械の取扱説明書と社内の作業標準に従う。

  1. 暖機運転

    砥石軸と工作物軸を回して温度を安定させる。

  2. 治具の取付け

    工作物を支えるアーバやクランプを付け、振れを確認する。

  3. 砥石の取付けとバランス

    砥石を付け、バランスを取って試運転する。

  4. ドレッシング

    ダイヤロールでねじ状砥石の山の形をつくる。

  5. 歯溝合わせ（センタリング）

    工作物の歯溝の位置をセンサで測り、砥石の山が歯溝の真ん中に入るよう合わせる。

  6. 試し研削と測定

    歯車測定機で歯形・歯すじ・ピッチを測る。

  7. 修整値の補正

    測定結果をもとに修整量や圧力角を補正する。

  8. 量産と定期ドレス

    決めた個数ごとにドレスし、砥石を少しずつずらして（シフト）新しい部分で削る。

03知っておくべきこと

削る・磨くといった主な機能の陰で、仕上がりと安全を左右する作業や現象がある。トラブルの多くはここから起きる。

ドレッシングが歯形を決める

ねじ状砥石の山の形はドレッシングでつくられ、その形がそのまま歯車の歯形になる。ドレス条件やダイヤロールの摩耗が歯形の精度と面に直結する。ダイヤロールは諸元ごとの専用品で高価なため、使用回数を管理する。

歯溝合わせが甘いと片当たりになる

砥石の位置が歯溝の真ん中からずれると、片側の歯面だけ多く削れ、取り代が足りない面が残る。

研削焼け

歯面の一部が焼けると、強度と寿命が落ちる。ナイタルエッチングで検査する。

取り代のばらつき

熱処理ひずみが大きいと、場所によって削る量が大きく変わり、焼けや削り残しの原因になる。前工程と一緒に管理する。

騒音と表面のうねり

電気自動車ではエンジン音がなく、歯車の音が目立つ。歯面の細かなうねりが特定の音を生むため、砥石の使い方やドレス条件まで含めて対策する。

砥石の安全と法定の決まり

砥石は高速で回るため、割れると破片が飛ぶ。取付け前に外観のひびを確認し、ビトリファイド砥石は木づちで軽くたたく打音検査で濁った音がしないかを見る。最高使用周速度を超えて使ってはならず、日本の労働安全衛生規則では、作業開始前に1分以上、砥石を交換したときは3分以上の試運転が求められる。砥石の取替えと試運転は特別教育を受けた人が行う業務で、保護カバーを外したままの運転は厳禁である。

04想定問答

仕様の打ち合わせで、お客様から実際によく聞かれる質問と、その答え方の例。数値をその場で約束せず、条件を確かめてから根拠とともに答えるのが基本である。

Qホブ切り＋シェービングから研削に替える必要はありますか。

A電気自動車や静かさが求められる歯車では、熱処理ひずみを取り除いて歯面を整える研削が必要になることが多いです。要求される精度等級と騒音の目標をお聞きして判断します。

確認のポイント研削にすると設備費とサイクルタイムが増える。必要な部品を見極める。

Q連続創成研削と成形研削、どちらがいいですか。

A量産の中小モジュールなら能率の高い連続創成研削、大きなモジュールや少量・多品種、特殊な歯形なら成形研削が向きます。

確認のポイント歯車の大きさと生産量で決まる。

Qダイヤロールドレッサは品種ごとに必要ですか。

A総形のダイヤロールは歯車の諸元ごとに専用です。品種が多い場合は、NCで砥石の形をつくる方式で費用を抑えられます。

確認のポイントダイヤロールの費用と納期は大きい。品種数を必ず聞く。

Q歯面のうねりで騒音が出ると言われました。対策はありますか。

A砥石の使い方（シフト）、ドレス条件、機械の振動の管理で、特定の騒音の原因になる歯面のうねりを抑えます。測定と解析の方法も含めてご提案します。

確認のポイント騒音は完成品の試験で初めてわかることが多い。測定のフィードバック体制を一緒に考える。

Q1台で何個／時間くらい削れますか。

Aモジュール、歯数、歯幅、取り代、要求精度から試算します。取り代のばらつき（熱処理ひずみ）が大きいと時間が延びるため、前工程のデータもいただけると精度の高い試算ができます。

確認のポイント前工程の管理で研削時間が変わることを伝える。

どの機械でも聞かれること

Q納期と、立ち上がるまでの期間はどのくらいですか。

A機械本体の納期に加えて、据付け・試運転・初品確認・量産立上げまでを工程表にしてお出しします。御社のワーク・治具・自動化を含めた形でお約束できる日程を、仕様が固まった時点で確定させてください。

確認のポイント機械単体の納期だけを答えると、治具・ローダ・プログラムの準備で立上げが遅れたときに食い違う。検収条件（何個連続で、どの寸法がCpk何以上か）を同時に決めておく。

Q故障したとき、どのくらいで来てもらえますか。部品はありますか。

Aサービス拠点からの出動の目安と、主軸・NC・サーボなど止まると困る部品の在庫・取り寄せ期間をメーカーに確認してお答えします。止められない設備でしたら、予備品として持っておくべき部品の一覧もご提案します。

確認のポイント「すぐ行きます」とは言わない。夜間・休日の対応範囲、リモート診断の有無、保証期間と保証の対象外（消耗品・誤操作）を文書で示す。

Qオペレータや保全の教育はしてもらえますか。

A操作・プログラム・日常点検・定期保全の教育内容と日数、場所（メーカーの研修施設か御社か）をご提示します。立上げ時に誰が何を担当するかも一緒に決めましょう。

確認のポイント教育の範囲が曖昧だと、引き渡し後の問い合わせが増える。操作説明書・保全マニュアル・電気図面の提出範囲も確認する。
