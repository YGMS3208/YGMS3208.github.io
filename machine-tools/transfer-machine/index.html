専用機・トランスファーマシン

専用機とは、特定の部品の決まった加工だけを高い能率で行うよう設計した工作機械である。そのうち複数の加工ステーションを搬送装置でつなぎ、工作物を順送りして連続加工するものをトランスファーマシンという。

構造と仕組み

専用機は、標準化した部品（ユニット）を組み合わせてつくることが多い。主な構成は、工具を回す主軸ヘッド、ヘッドを前後に送るスライドユニット、ベッド、工作物を決まった位置に固定する治具である。多軸ヘッドは、1つのモータから歯車列で多数の主軸を回し、穴の配置に合わせて並べたドリルやタップで多数の穴を同時にあける。送りには油圧のほか、サーボモータとボールねじで動かすNC化したユニットも使われる。

トランスファーマシンは、こうした加工ステーションを一直線や回転テーブルの上に並べる。すべてのステーションが同時に加工したあと、搬送装置が工作物を一斉に次のステーションへ送る。工作物を直接運ぶ方式と、治具付きのパレットに載せて運ぶ方式がある。各ステーションは穴あけ、タップ立て、中ぐり（穴を広げて仕上げる加工）などを分担し、ライン全体のサイクルタイムは最も時間のかかるステーションで決まる。

部品と工程に合わせて作り込むため、1個あたりの加工時間が短く、品質も安定する。一方、部品の設計が変わると改造が必要で、生産量が少ないと設備の負担が重い。この弱点を補うため、横形マシニングセンタやNCユニットを搬送装置でつなぎ、プログラムの変更で複数の部品に対応するフレキシブルトランスファライン（FTL）も使われる。

得意な加工と自動車部品での例

専用機・トランスファーマシンは、形の決まった部品を大量に、同じ品質で加工し続けるのが得意である。シリンダーブロックやシリンダーヘッドでは、ボルト穴や油・水の通路の穴あけとタップ立て、バルブまわりの穴加工をステーションに分けて行う。クランクシャフトの細く長い油穴あけや、コネクティングロッドの大端部を破断して2つに分ける工程にも専用機が使われる。デフケース、ステアリングナックル、ハブベアリングのボルト穴のように穴の配置が決まった加工は、多軸ヘッドで同時に行える。設計変更が多い部品や生産量が読みにくい部品では、横形マシニングセンタを並べたラインが選ばれることが多い。

選ぶときのポイント

  • 生産量、部品の生産期間、設計変更の見込みを整理し、専用化してよい範囲を決める。
  • 必要なタクトタイムから工程を分け、ステーションごとの負荷をそろえる。
  • 1か所が止まるとライン全体が止まるため、工具交換のしやすさと故障からの復旧を重視する。
  • 将来の機種追加に備え、NCユニット化や治具交換で対応できる構造かを確認する。
  • 立ち上げまでの期間と、試し加工で精度を確かめる方法を計画に入れる。

自動化との組み合わせ

トランスファーマシンは、工作物の搬送・位置決め・加工がもともと一体で自動化されている。前後の工程とはコンベヤやロボットでつなぎ、途中に計測ステーションを入れて穴の位置や径を確認する。ラインの一部が止まっても全体が止まらないよう、途中にバッファ（工作物を一時的にためる場所）を設ける。工具寿命の管理や主軸負荷の監視で、工具交換と保全の時期を計画的に決めることが稼働率を保つ鍵になる。

02使い方の流れ

電源を入れてから1個目を仕上げ、量産に移るまでの標準的な流れ。実際の手順と数値は、機械の取扱説明書と社内の作業標準に従う。

  1. 始業点検

    油圧、エア、潤滑油の量と圧力、各ユニットの位置を確認する。

  2. 原点復帰と運転準備

    全ステーションを原点に戻し、自動運転の準備をする。

  3. 初品確認

    最初の1個の全項目を測り、合格を確認してから流す。

  4. 自動運転

    ラインの状態と寸法の変化を監視する。

  5. 工具の計画交換

    決めた加工数で工具を交換し、交換後は寸法を確認する。

  6. 異常時の処置

    止まった位置と原因を確認し、手順どおりに手動操作で復帰させる。

  7. 終業時

    切りくずの清掃と、位置決め面の清掃を行う。

03知っておくべきこと

削る・磨くといった主な機能の陰で、仕上がりと安全を左右する作業や現象がある。トラブルの多くはここから起きる。

1か所止まれば全部止まる

ステーションが直列につながっているため、1か所の故障や工具交換がライン全体を止める。可動率を上げるには、止まりやすい場所を記録して対策する。

位置決めの基準

工作物は基準の穴と面で位置を決める。そこに切りくずがあると、以降のすべての工程がずれる。

ばらつきの切り分け

寸法がずれたら、どのステーションで起きたかを切り分ける。ステーションごとの測定記録が役立つ。

手動操作の安全

異常処置で機械に入るときは、電源とエネルギーを遮断して施錠する（ロックアウト）。インターロックを外して作業しない。

工具交換後の確認

工具を替えた直後は寸法が変わりやすい。交換後の1個目を必ず測る。

04想定問答

仕様の打ち合わせで、お客様から実際によく聞かれる質問と、その答え方の例。数値をその場で約束せず、条件を確かめてから根拠とともに答えるのが基本である。

Q汎用機を並べるのと、専用機にするのとで、どちらが得ですか。

A同じ部品を長い期間・大量に流すなら、専用機のほうが1個あたりの費用を下げられます。モデルチェンジの予定と生産期間をお聞きして、汎用機ラインと比較します。

確認のポイント専用機は転用が難しい。生産期間の見通しが判断の鍵。

Qモデルチェンジのとき、改造で対応できますか。

A加工ヘッドや治具を交換できる構成にしておけば、改造で対応できる範囲が広がります。どの程度の変更まで対応できるかを、最初の仕様で決めておきます。

確認のポイント改造の範囲を後から広げるのは難しい。最初に決める。

Q立会いでは何を確認するのですか。

A決めた個数を連続で加工し、重要寸法の工程能力（Cpkなど）、サイクルタイム、可動率を確認します。合格基準を発注時に決めておきましょう。

確認のポイント基準が曖昧だと検収が長引く。数値で決める。

Q故障で止まったときのラインへの影響が心配です。

A1か所の停止がライン全体を止めるため、止まりやすい場所の予備品、バッファ（仕掛品を一時的にためる場所）、保全の体制を一緒に計画します。

確認のポイント可動率の目標と、その計算方法をそろえる。

Q図面やプログラムは引き渡してもらえますか。

A機械図面・電気図面・プログラムの提出範囲を、契約の段階で決めます。社内で保全・改造を行う予定があれば、その範囲もお知らせください。

確認のポイント引き渡し範囲は後のトラブルの元になりやすい。文書で明確にする。

どの機械でも聞かれること

Q納期と、立ち上がるまでの期間はどのくらいですか。

A機械本体の納期に加えて、据付け・試運転・初品確認・量産立上げまでを工程表にしてお出しします。御社のワーク・治具・自動化を含めた形でお約束できる日程を、仕様が固まった時点で確定させてください。

確認のポイント機械単体の納期だけを答えると、治具・ローダ・プログラムの準備で立上げが遅れたときに食い違う。検収条件（何個連続で、どの寸法がCpk何以上か）を同時に決めておく。

Q故障したとき、どのくらいで来てもらえますか。部品はありますか。

Aサービス拠点からの出動の目安と、主軸・NC・サーボなど止まると困る部品の在庫・取り寄せ期間をメーカーに確認してお答えします。止められない設備でしたら、予備品として持っておくべき部品の一覧もご提案します。

確認のポイント「すぐ行きます」とは言わない。夜間・休日の対応範囲、リモート診断の有無、保証期間と保証の対象外（消耗品・誤操作）を文書で示す。

Qオペレータや保全の教育はしてもらえますか。

A操作・プログラム・日常点検・定期保全の教育内容と日数、場所（メーカーの研修施設か御社か）をご提示します。立上げ時に誰が何を担当するかも一緒に決めましょう。

確認のポイント教育の範囲が曖昧だと、引き渡し後の問い合わせが増える。操作説明書・保全マニュアル・電気図面の提出範囲も確認する。
