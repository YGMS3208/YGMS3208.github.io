AUTOMATION

ロボットによるワーク着脱

ロボットによるワーク着脱とは、産業用ロボットが工作機械へのワーク（工作物）の取付けと取外しを行い、加工を人手なしで連続させる方法である。ロボット、工作機械、ワークの置き場、安全柵をひとまとめにした単位をロボットセルと呼ぶ。

  1. 1
    工作機械ドアを自動で開け閉めする
  2. 2
    ロボット6軸の多関節ロボット。工作物を出し入れする
  3. 3
    ハンド工作物に合わせた爪でつかむ
  4. 4
    安全柵人が近づくと止まるよう囲う（協働ロボットでは省けることもある）
  5. 5
    ワークストッカ素材と完成品を並べる

仕組み

主に使われるのは、人の腕に似た6つの関節を持つ垂直多関節ロボットである。先端のハンド（グリッパ）でワークをつかみ、機械の前面の自動扉から機内へ入れて、チャックや治具に取り付ける。ハンドを2つ持つダブルハンドにすると、取外しと取付けを1回の進入で済ませられる。

ワークは、整列させたトレーやパレット、コンベヤから供給する。カメラで位置を認識するビジョンを使えば、ばら置きのワークを拾うこともできる。ロボットと機械は「加工完了」「扉開」「チャック開閉」などの信号で連携する。

ロボットが同じ位置へ戻る繰返し性は、一般に工作機械よりも粗い。そのため、最終的な位置決めは機械側のチャックや治具の基準面で行い、ロボットは確実に置く役割に徹するのが基本である。

協働ロボットは、人と同じ空間で働くことを前提に、接触したときの力を検知して止まる機能などを持つロボットである。国内では、モータの定格出力が80Wを超える産業用ロボットには柵などの措置が求められるが、リスクアセスメントで危険のおそれがなくなったと評価できれば、柵を設けずに人と協働させることができる。

種類と特徴

種類特徴向いている生産
産業用ロボット（安全柵付き）動作が速く、重いワークも扱える。柵で囲い、人の立入りで止める中量から大量の生産
協働ロボット条件を満たせば柵なしで使え、移設もしやすい。動作速度と可搬質量は小さめ少量多品種、既存機への後付け
走行軸付きロボット床のレール上を走り、1台で複数の機械を受け持つ加工時間の長い機械を何台も回す工程
台車搭載・移動形無人搬送車などに載せ、必要な機械へ移動して作業する機械ごとの稼働が少ない現場の夜間運転

向いている生産と導入のポイント

ロボットはガントリーローダより動きの自由度が高く、着脱のほかにエアブロー、バリ取り、計測器へのセット、ワークの反転などの付帯作業もこなせる。機械の前面から作業するため、既存の機械に後付けしやすい。品種ごとにプログラムやハンドを切り替えられるので、中量生産から少量多品種まで幅広く使える。

導入では、ワークの供給方法とストッカの容量を最初に決める。無人で動ける時間の目安は、ストッカに置けるワークの数に1個あたりのサイクルタイムを掛けた値である。次に、ハンドの形と把持位置、機内での干渉、扉の自動化を検討する。動作の教え込み（ティーチング）には時間がかかるため、パソコン上で動作を作るオフラインティーチングを使うこともある。

注意点

  • 協働ロボットでも、ハンドやワークに鋭い部分や刃物があれば、柵や速度制限が必要になる場合がある。用途ごとのリスクアセスメントが前提である。
  • 旋削で出る長い切りくずがハンドやワークに絡むと、つかみ損ないの原因になる。
  • 機械の前面をロボットが使うため、作業者の段取りや点検の動線と重ならないよう配置する。
  • 非常停止や停電の後に、ワークを持ったままの状態からどう復帰するかを決めておく。
  • 無人運転では工具の摩耗や折損が見つけにくい。工具寿命の管理や折損検知と組み合わせる。
