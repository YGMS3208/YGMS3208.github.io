COMPONENT

NC装置

NC装置とは、加工プログラムを読み取り、工具や工作物の位置・送り速度・主軸回転数などを数値で指令して工作機械を自動で動かす制御装置である。現在はコンピュータを内蔵したCNCが主流である。

    表示画面プログラム・座標・負荷などを表示する
  2. 2
    運転ボタン自動運転の起動・停止、モード切替
  3. 3
    操作キープログラムの入力・編集をする
  4. 4

  5. 5

  6. 6
    非常停止押すと機械をすぐに止める

仕組み

加工プログラムは、移動や加工の種類を指令するGコード、クーラントのオン・オフなどを指令するMコード、送り速度のF、主軸回転数のS、工具番号のTなどで書かれる。NC装置はプログラムを解読し、指令された経路を細かい移動量に分ける補間（直線補間・円弧補間）を行って、各軸のサーボアンプに位置指令を送る。そしてサーボモータの検出器から戻る位置と指令を比べ、誤差をなくすように制御する。工具交換やチャックの開閉、扉のインターロックなどの順序制御は、内蔵のPLC（プログラマブルロジックコントローラ）が受け持つ。

主な機能に、工具の長さや径の違いを補う工具補正、加速と減速をなめらかにする加減速制御、多数のブロック（プログラムの行）を先読みして角の手前で減速する先読み制御がある。ボールねじのピッチ誤差補正、バックラッシ補正、熱変位補正のように、機械の誤差を打ち消す機能も持つ。プログラムは、画面で質問に答えて作る対話形プログラミングや、設計データから工具経路を作るCAD/CAMで作成する。画面上で工具経路を描いて確かめたり、工具と治具の干渉を事前に調べたりする機能も備える。

種類と特徴

種類特徴主な用途
位置決め制御点から点へ移動し、移動中は加工しない穴あけ用の専用機
輪郭制御複数の軸を同時に動かし、直線・円弧・曲面を削るマシニングセンタ、NC旋盤

工作機械での役割と精度への影響

NC装置は機械の頭脳にあたり、同じ機械本体でも制御の性能で加工精度と能率が変わる。一般に指令の最小単位は0.001mmで、高精度機ではさらに細かい単位で指令する。曲面加工では、先読みと加減速の制御が面のなめらかさとサイクルタイムを両立させる鍵になる。補正機能はボールねじのピッチ誤差や熱変位を打ち消し、機械本体の精度を引き出す。5軸マシニングセンタや複合加工機では、工具の向きが変わっても刃先の位置を保つ制御（工具先端点制御）が加工精度を左右する。ホブ盤やギヤスカイビング盤では工具と工作物の回転を電子的に同期させ、変速機ギヤやe-Axle減速機ギヤの歯を削る。量産ラインでは、ローダやロボットとの信号のやり取りや、測定結果による工具補正値の自動更新も担う。

点検・保守とトラブルの兆候

  • パラメータ、加工プログラム、補正値のバックアップを定期的に取る。基板の故障やデータ消失からの復旧に必要である。
  • メモリ保持用の電池は、取扱説明書の手順に従って定期的に交換する。
  • 制御盤の冷却ファンやフィルタ、熱交換器が詰まると盤内の温度が上がり、誤動作や故障の原因になる。
  • 扉のパッキンが劣化すると、切削油のミストや粉じんが制御盤に入る。
  • アラーム履歴を記録して傾向を見ると、同じ部位の異常を早く見つけられる。
  • 補正値の入力ミスは衝突につながるため、変更時は二重に確認する。
