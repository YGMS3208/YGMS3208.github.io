COMPONENT

チャックとワーク保持

チャックとは、旋盤などの主軸先端に取り付け、爪で工作物をつかんで主軸とともに回転させる保持具である。ワーク保持にはチャックのほか、コレット、治具、センタなどの方式があり、加工精度を大きく左右する。

  1. 1
    チャック本体主軸の先端に取り付ける
  2. 2
    油圧シリンダドローチューブを引いて爪を閉じる
  3. 3
    マスタージョー本体の溝を半径方向に動く
  4. 4
    生爪（トップジョー）工作物に合わせて削って使う柔らかい爪
  5. 5
    工作物爪で外径をつかむ

仕組み

NC旋盤で一般的なパワーチャックは、主軸後端の油圧シリンダが中空の主軸を通るドローチューブを引き、くさびやレバーで3つの爪を半径方向に同時に動かす。爪がそろって動くため、工作物の中心が自動で主軸中心に合う。爪には焼入れした硬爪と、軟らかい鋼の生爪がある。生爪は機械に付けたまま工作物の形に合わせて削れるため、振れを小さくできる。把持力は油圧シリンダの圧力で調整するが、外径をつかむ場合は、高速回転の遠心力で爪が外へ引かれて把持力が下がる。

コレットは、すり割りを入れたスリーブをテーパで締めて、棒材を全周から均一につかむ。治具は、マシニングセンタで工作物を基準面や基準穴で位置決めし、油圧クランプなどで固定する。位置決めでは、3方向の移動と3方向の回転の6つの自由度を過不足なく拘束するのが基本である。センタは、軸の両端に開けたセンタ穴を円すい形のセンタで支える方式で、回転は端面ドライバなどで伝える。このほか、薄い板ばねのたわみを使って変形を抑えながらつかむダイヤフラムチャックは、歯車研削盤や内面研削盤で歯車を保持するときに使われる。

種類と特徴

種類特徴主な用途
パワーチャック油圧で爪を自動開閉し、ローダやロボットと組み合わせやすいNC旋盤の量産加工
スクロールチャックうず巻き状のねじで爪を同時に動かす手動式単品・少量の旋削
コレットチャック全周を均一につかみ振れが小さいが、つかめる径の範囲は狭い主軸移動形自動旋盤、棒材の加工
油圧クランプ治具基準で位置決めし、複数か所を同時に締める横形マシニングセンタでのシリンダーブロック、トランスミッションケース
センタと端面ドライバ両端を支えるため同軸度が出やすい円筒研削盤でのクランクシャフト、変速機シャフト
マグネットチャック磁力で工作物を吸着する平面研削盤

工作機械での役割と精度への影響

保持の繰返し精度と、つかんだことによる変形が、真円度や同軸度に直結する。マシニングセンタの治具では、位置決めの基準を前工程とそろえることが穴位置の精度を保つ基本で、シリンダーブロックやトランスミッションケースでは、最初に基準面と基準穴を加工して以降の工程の基準にする。薄肉のアルミ部品は把持力でたわみ、加工後に外すと元に戻って真円度が悪化する。そのため、モータ・e-Axleハウジングやアルミホイールの旋削では、把持力を調整したり、つかむ点を増やして力を分散させたりする。ブレーキディスクロータやハブベアリングの量産旋削では、2工程目で1工程目の加工面をつかみ、表裏の同軸度を確保する。自動化ラインでは、工作物が正しく着座したかをエアの流れで確かめ、着座不良による不良品を防ぐ。

点検・保守とトラブルの兆候

  • 把持力を専用の測定器で定期的に測る。爪の摺動部の給脂不足は、把持力低下の主な原因である。
  • 切りくずやスラッジ（細かい削りかすの泥）が入ると爪の動きが重くなるため、定期的に分解清掃する。
  • チャックごとに決められた許容回転数を超えて使わない。
  • 治具の位置決めピンや着座面の摩耗、クランプの押付け力も定期的に確認する。
  • 生爪を成形するときは、実加工と同じ把持圧と把持径で削る。
  • 油圧の低下や、回転部に油を送るロータリージョイントからの漏れは、把持力不足の兆候である。
