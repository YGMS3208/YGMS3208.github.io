ULTRA-PRECISION

超精密加工機：ナノメートルの面をつくる

レンズの金型、反射鏡、光学部品。鏡のような面と、ナノメートル単位の形をつくる超精密加工機は、ふつうの工作機械と何が違うのか。単結晶ダイヤモンド工具、空気や油で浮かせる軸受と案内、温度と振動の管理、削れる材料と削れない材料、測り方までをまとめる。

何をつくる機械か

超精密加工機は、形の誤差がサブマイクロメートル（0.1μm）以下、面粗さがナノメートル単位という、ふつうの工作機械より1〜2桁高い精度で削る機械である。つくるのは主に光に関わる部品で、スマートフォンや車載カメラのレンズをつくる金型、レーザ用の反射鏡、プロジェクタや計測機の光学部品、回折格子などがある。研磨せずに、削っただけで鏡のような面に仕上げる。

ふつうの工作機械との違い

項目ふつうの工作機械（目安）超精密加工機（目安）
主軸の軸受転がり軸受空気静圧軸受（空気の膜で浮かせる）
案内リニアガイド・すべり案内油静圧・空気静圧の案内（接触しない）
駆動サーボモータ＋ボールねじリニアモータ（直接駆動）
位置の分解能0.1〜1μm1nm以下
工具超硬・CBN単結晶ダイヤモンド（刃先の丸みが数十nm）
環境一般の工場恒温室（±0.1℃級）、除振台

接触しない軸受と案内は、摩擦がほとんどなく、動きが滑らかで、回転の誤差も小さい。ボールねじの代わりにリニアモータで直接動かすのは、ねじの細かな誤差や振動を避けるためである。

ダイヤモンド切削と延性モード

単結晶ダイヤモンドの刃先は、研いだ刃物の中で最も鋭くできる。その刃先で、切込みを数μm以下にして削ると、材料はちぎれずに滑らかに流れ、鏡のような面になる。

  • 延性モード加工：ガラスやシリコンのようにもろい材料でも、切込みをごく小さく（数十〜数百nm）すると、割れずに延びるように削れる。赤外線レンズのゲルマニウムやシリコンを削るときに使う。
  • 削り方：旋盤のように回して削るダイヤモンド旋削、回る工具で溝や非対称の形を削るフライカット、工具をごく速く前後させて自由な形をつくる高速工具サーボ（FTS）などがある。

削れる材料、削れない材料

材料ダイヤモンド切削使い方
無電解ニッケルめっきよく削れる鋼の金型の表面に厚くめっきして、その層を削る。レンズ金型の定番
銅・アルミ・真ちゅうよく削れる反射鏡、ヒートシンク付きの光学部品
ゲルマニウム・シリコン・一部のガラス延性モードで削れる赤外線レンズ
樹脂（PMMAなど）削れる試作のレンズ、導光板
鉄・鋼削れない（ダイヤモンドが化学的に摩耗する）超音波で工具を振動させる方法や、研削・研磨で仕上げる

鉄がダイヤモンドで削れないのは、高温で鉄が炭素（ダイヤモンド）と反応し、刃先が急に摩耗するためである。このため鋼の金型は、表面にニッケルをめっきしてから削る。

温度・振動・空気の管理

  • 温度：鋼は1℃・100mmで約1.2μm伸びる。ナノメートルの加工では、室温を±0.1℃程度に保ち、機械の油や空気の温度も管理する。加工の前に機械と工作物を十分になじませる。
  • 振動：床の振動、近くのプレス、人の歩行まで影響する。除振台（空気ばね）に機械を載せ、振動源から離して置く。
  • 空気：空気静圧軸受には、乾燥してきれいな空気を安定した圧力で送る。ちりや水分は軸受の故障につながる。

測り方

ナノメートルの形は、触って測ると傷が付くうえ、測定器の精度が足りない。レーザ干渉計や白色干渉計を使った非接触の形状測定機、触針の力をとても小さくした超精密の形状測定機で、形の誤差を測る。測った誤差をもとに工具の経路を補正して、もう一度削る（補正加工）ことで、形の精度を上げていく。

数値の扱いこのページの数値は一般的な目安である。機械と用途によって大きく違うため、メーカーの仕様で確かめること。
