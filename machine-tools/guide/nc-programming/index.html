NC PROGRAM

NCプログラムの基本：Gコード・座標系・工具補正

NCプログラムの読み方を、はじめての人にもわかるように。主なGコードとMコードの一覧、機械座標とワーク座標、工具長補正の3つの方式、工具径補正、固定サイクル、注釈付きのプログラム例、そして動かす前の確かめ方まで。

NCプログラムのしくみ

NCプログラムは、1行（ブロック）ごとに「アドレス（英字）＋数値」を並べた命令の列である。たとえば G01 X50. F300 ; は「直線で（G01）、X50の位置まで、毎分300mmで動け」という意味になる。

アドレス意味例
G準備機能：動き方や座標系を決めるG00 早送り、G01 直線、G54 ワーク座標
M補助機能：機械の補助的な動作M03 主軸正転、M06 工具交換、M08 クーラント
X・Y・Z（U・W）位置（旋盤のXは直径で指令するのが一般的）X50. Z-20.
F送り速度F300（mm/min）、F0.2（mm/rev）
S主軸の回転数（周速一定制御では切削速度）S3800
T工具番号（旋盤では補正番号も含む）T01、T0101
H・D工具長補正・径補正の番号（マシニングセンタ）H01、D01

多くのGコードは、一度指令すると取り消すまで有効なモーダルである。G01を指令した後は、次の行でGを書かなくても直線で動く。安全のため、プログラムの先頭と工具交換の後に、モーダルを決まった状態に戻す「安全ブロック」を入れる。

メーカーで違うGコードの基本は共通だが、細部の書式、使える機能、パラメータの初期状態はNC装置のメーカーと機種で違う。ここでは広く使われる書き方で説明している。実機では必ず取扱説明書で確かめること。

Mコードの多くは機械メーカーが決めるため、チャックの開閉、ドア、チップコンベヤ、ロボットとの信号などは機種ごとに番号が違う。

座標系と工具長補正

機械には、電源を入れて原点復帰した位置を基準にした機械座標がある。プログラムは図面の基準（工作物の角や中心）を原点にして書きたいので、その位置を機械座標で測ってワーク座標（G54など）に登録する。工具は1本ずつ長さが違うため、その差を工具長補正（G43 H）で足し合わせる。

工具長の測り方と、それに合わせたG54のZの入れ方には3つの方式があり、どれを使っているかで補正値の符号と意味が変わる。工場の中で方式をそろえ、段取り表に書いておく。

方式工具長（H）に入れる値G54のZに入れる値特徴
ゲージライン基準主軸端（ゲージライン）から刃先までの長さ（＋の値）ゲージラインが工作物の上面に来るときの機械座標工具を機外のプリセッタで測れる。いちばん一般的
マスター工具基準基準工具との長さの差（＋・−がある）基準工具の先端が上面に来るときの機械座標基準工具が折れると全工具の測り直しになる
ワーク上面基準刃先が工作物の上面に触れたときの機械座標（−の値）0（またはわずかな値）機上で工具ごとに当てて測る。工作物が替わると測り直し

工具径補正（G41・G42）とノーズR補正

エンドミルで輪郭を削るとき、プログラムは図面の形をそのまま書き、工具の半径の分は径補正でずらす。G41は進行方向の左に、G42は右に工具を寄せる。主軸を正転（M03）させて外側の輪郭をG41で削ると、ダウンカットになる。

  • 補正は、工具の半径より長い直線の動きでかける（G41/G42）・消す（G40）。円弧の途中や、動きのない行でかけない。
  • 補正をかけたまま、工具の半径より小さい内側の角や溝は削れない（アラームか削り込み）。
  • 工具が摩耗して寸法が太るときは、補正値（D）を小さくして直す。プログラムは触らない。
  • 旋盤では、刃先の丸み（ノーズR）のためにテーパや円弧で削り残しや削り込みが出る。G41/G42と、刃先の向きを表す「仮想刃先番号」を設定して補正する。端面や外径の真っすぐな部分だけなら影響はない。

固定サイクル

穴あけのように決まった動きは、固定サイクルで1行にまとめる。

コード動き使う場面
G81R点まで早送り→穴の底まで切削→早送りで戻る浅い穴、センタ穴
G83少し削っては穴の外まで戻る（ペック）を繰り返す深い穴。切りくずを外に出す
G73少し削っては少しだけ戻る（切りくずを切る）やや深い穴を速く
G84主軸と送りを同期させてタップを立て、逆転して抜くめねじ（同期タップ）
G80固定サイクルの取消しサイクルの後に必ず

R点は早送りから切削送りに切り替える高さ（工作物の2〜3mm上）。穴をあけた後に戻る高さは、G98で初めの高さ（イニシャル点）、G99でR点になる。穴と穴の間にクランプや段差があるときはG98にして、ぶつけないようにする。

動かす前の確かめ方

  1. 画面で軌跡を見る：NC装置やCAMのシミュレーションで、工具の経路が図面どおりか、早送りで工作物やクランプに当たらないかを見る。
  2. マシンロック：軸を動かさずにプログラムを走らせ、アラームや座標の誤りを見つける。
  3. エアカット：ワーク座標のZを上（＋）にずらして、空中で実際の速さで動かす。ずらすのは外部ワーク座標などに入れ、戻し忘れないよう記録する。
  4. シングルブロック＋オーバライド：1行ずつ、早送りを絞って動かし、残りの移動量を見ながら最初の1個を削る。

よくある誤り：小数点の抜け（設定によっては X10 が0.01mmと読まれる）、G91（増分）のまま戻し忘れる、補正番号の取り違え（H02の工具にH01）、G41の入れ方の誤り、固定サイクルの後のG80の書き忘れ。

原点復帰・アラームと、途中からの再開

  • オーバトラベル：ソフトリミット（NCの設定）を超えると止まる。反対方向に手動で戻して解除する。ハードリミット（リミットスイッチ）まで行った場合は、機種ごとの手順で解除し、原因（座標や補正の誤り）を必ず確かめる。
  • 非常停止からの復帰：原因を取り除いてから解除し、原点復帰が必要な機種では原点復帰してから動かす。工具と工作物が当たったまま止まっていないか確かめる。
  • 途中からの再開：途中の行から始めると、それより前で指令したモーダル（G90/G91、G43、主軸の回転、クーラント、ワーク座標）が抜ける。再開用の安全ブロックを用意するか、NC装置のプログラム再開機能を使う。

CAM・ポストプロセッサとマクロ

曲面や5軸の加工は、CAMで工具経路をつくり、ポストプロセッサでその機械のNCプログラムに変換する。ポストが機械と合っていないと、工具交換や回転軸の動きで事故が起きるため、新しい機械やポストでは必ずシミュレーションとエアカットで確かめる。

マクロプログラムは、変数・計算・条件分岐を使えるNCプログラムで、同じ形を寸法違いで使い回したり、機上計測の結果で補正値を自動で書き換えたりするのに使う。

技能検定との関係

国家検定の機械加工職種には、数値制御旋盤作業やマシニングセンタ作業などの作業区分があり、学科と実技で、プログラム、段取り、測定の力が問われる。出題の範囲と形式は、中央職業能力開発協会が公開している試験の資料で確かめてほしい。このページの内容と、各機種の操作トレーニングは、その土台になる。
