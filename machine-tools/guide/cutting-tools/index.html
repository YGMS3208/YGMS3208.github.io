切削工具の種類・材種と、傷み方の見分け方

バイト、スローアウェイチップ、エンドミル、ドリル。工具の種類と、超硬・サーメット・CBNなどの材種、コーティング、チップの記号の読み方、そして工具の傷み方から原因を見分ける方法までをまとめる。

工具の種類

加工主な工具使う機械ポイント
外径・端面の旋削外径バイト（スローアウェイチップ式）旋盤・複合加工機チップの形（ひし形80°・55°・35°、三角、丸）で、削れる形と刃先の強さが変わる
内径の旋削ボーリングバー（中ぐりバイト）旋盤突出しが長くなるので、びびり対策が中心。超硬バー・防振バー
溝入れ・突切り溝入れバイト旋盤刃幅が狭く、切りくずが詰まりやすい。送りは小さめ
ねじ切りねじ切りバイト旋盤数回に分けて切り込む。ねじの山の角度に合ったチップ
平面正面フライスマシニングセンタ多数のチップで広い面を速く削る。切込み角で切りくずの厚さが変わる
側面・溝・形状エンドミル（スクエア・ボール・ラジアス）マシニングセンタソリッド（一体の超硬）が主流。ボールは曲面、ラジアスは角の丸みと強さ
穴あけドリル（超硬ソリッド、刃先交換式）マシニングセンタ・旋盤深さが直径の3倍を超えたら、ステップ送りか内部給油

チップの記号を読む（例：CNMG120408）

位置記号意味
1文字目C形：80°のひし形（W＝80°の三角に近い形、D＝55°、V＝35°、T＝三角、S＝四角、R＝丸）
2文字目N逃げ角：0°（ネガ。両面を使える）。Pは11°、Cは7°（ポジ。切れ味がよく、細い工作物や内径に向く）
3文字目M精度（許容差）の等級
4文字目G穴とブレーカの形（両面にブレーカ付き、取付け穴あり）
1212刃先の長さ（およそ12mm）
0404厚さ（4.76mm）
0808ノーズR：0.8mm（04＝0.4、12＝1.2）

このあとにメーカー独自のブレーカ記号と材種の記号が続く。ノーズRが大きいほど刃先は強く、同じ送りでも面は滑らかになるが、削る力が増えてびびりやすくなる。

工具材料（材種）

材料硬さ・熱への強さ粘り強さ向く加工
高速度工具鋼（ハイス）低いとても高いドリル・タップ・総形工具。低速、断続、小ロット
超硬合金高い高いいまの主役。旋削・フライス・ドリルのほとんど。コーティングと組み合わせる
サーメット高い（鉄と反応しにくい）中鋼の仕上げ旋削。光沢のある面が出る
セラミックスとても高い低い鋳鉄の高速加工、耐熱合金、焼入れ鋼
CBN（立方晶窒化ホウ素）ダイヤモンドに次ぐ低い焼入れ鋼の仕上げ（旋削で研削の代わり）、鋳鉄の高速加工
PCD（ダイヤモンド焼結体）最も高い低い高Siアルミの量産、銅、樹脂、CFRP。鉄は削れない（反応して摩耗する）

コーティング

超硬の表面に数μmの硬い膜を付けて、摩耗と熱から刃先を守る。付け方で性格が違う。

  • CVD（化学蒸着）：膜が厚く（10〜20μm程度）、酸化アルミニウム（Al₂O₃）の層が熱を遮る。鋼や鋳鉄の連続旋削で長持ちする。刃先は少し丸くなる。
  • PVD（物理蒸着）：膜が薄く（数μm）、刃先を鋭いまま保てる。TiAlN・AlCrN など。フライス、ドリル、ステンレス、耐熱合金、小径工具に向く。
  • アルミや銅には、溶着を防ぐため無被覆か、DLC（ダイヤモンドライクカーボン）の膜を使う。

工具の傷み方から原因を見分ける

工具の刃先は、条件の良し悪しを最もよく教えてくれる。交換するときに捨てる前に刃先を見て、傷み方を記録する習慣が、条件改善の近道になる。

傷み方見た目主な原因対策
逃げ面摩耗刃先の下側が平らにすり減る正常な摩耗。速く進むなら速度が高すぎる速度を下げる、耐摩耗性の高い材種にする
クレータ摩耗すくい面がくぼむ鋼の高速切削で切りくずの熱と拡散Al₂O₃のCVD膜、速度を下げる、送りを下げる
境界摩耗（ノッチ）切込みの境目に深い溝加工硬化した表面、黒皮、耐熱合金切込み角を変える、丸チップ、切込みを毎回少しずらす
構成刃先刃先に材料が溶着低速、粘い材料（低炭素鋼・ステンレス・アルミ）速度を上げる、鋭い刃、サーメット・コーティング、クーラントの潤滑性
チッピング刃先が細かく欠ける断続切削、びびり、刃先が弱い、硬い介在物刃先を強化（ホーニング）、靭性の高い材種、送りを下げる、びびり対策
欠損刃先が大きく割れる負荷が大きすぎる、摩耗の放置、切りくずのかみ込み条件を下げる、早めの交換、切りくずの処理を見直す
塑性変形刃先が熱で垂れ下がる速度・送りが高すぎて刃先が高温になる速度を下げる、耐熱性の高い材種、クーラント
熱き裂刃先に直角の細いき裂が並ぶフライスの断続切削で加熱と冷却を繰り返すクーラントを切る（乾式）か十分にかける、靭性の高い材種

切りくずの形と処理

切りくずは、加工がうまくいっているかを示すもう一つの手がかりである。形は4つに分けられる。

  • 流れ型：連続して流れ出る。面はきれいだが、長くつながって工作物や工具に絡む。ブレーカで折る。
  • せん断型・むしれ型：途中で割れる、または材料がむしれる。面が荒れやすい。
  • き裂型：鋳鉄のようなもろい材料で、細かく砕ける。

旋削で扱いやすいのは、長さ数cmで切れる「C形」「6の字」「9の字」の切りくず。チップブレーカには、使える切込みと送りの範囲（適用範囲）があり、その外では切りくずが切れない。目安として、切込みはノーズR以上、送りはノーズRの半分以下にとる。切りくずが絡む、伸びる、詰まる場合は、送りを上げる、ブレーカを替える、高圧クーラントを使う。

ホルダと振れ

回転工具では、ホルダの振れ（刃先が回るときの揺れ）がそのまま工具寿命に効く。振れが10μmあると、刃ごとの負担がそろわず、寿命が大きく落ちることが多い。焼ばめホルダや精度の高い油圧チャックでは、振れを3μm以下に抑えられる。主軸テーパとホルダの選び方はツールホルダと主軸テーパで説明している。

あわせて読む条件の計算は切削条件の決め方と計算、工具を使う機械の仕組みは立形マシニングセンタとNC旋盤。
