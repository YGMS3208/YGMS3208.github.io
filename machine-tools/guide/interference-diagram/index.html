HOW TO READ

干渉図・動作範囲図の見方

カタログの「最大加工径」や「ストローク」は、工具・治具・ワークを付けると実際には小さくなる。干渉図と動作範囲図の読み方と、マシニングセンタにワークと工具が収まるかを確かめる計算を、図と一緒に解説する。

3行で干渉図・動作範囲図は「どこまで動けて、どこで何とぶつかるか」を表した図。カタログの「最大加工径」「ストローク」は、工具や治具を付けると実際には小さくなる。自分のワーク・治具・工具を図の上に置いて確かめるのが正しい使い方である。

干渉図と動作範囲図の違い

図何が描いてあるか主に見る機種
動作範囲図（ワーキングレンジ）各軸が動ける範囲、主軸端とテーブルの距離、テーブルの大きさなど、加工できる空間の大きさマシニングセンタ、5軸、門形
干渉図（インターフェアレンス）刃物台の旋回、チャック、心押台、ATCの工具など、動いたときにぶつかる可能性のある範囲NC旋盤、複合加工機、5軸
工具干渉図（ツーリング図）刃物台の各ステーションに付けた工具の位置と、突き出せる長さの上限NC旋盤、主軸移動形自動旋盤

NC旋盤の干渉図の読み方

  • 最大振り：ベッドやカバーにぶつからずに回せる最大の径。最大加工径はそれより小さく、刃物台が届いて削れる最大の径である。ワークがこの2つの間にあるなら、回せても削れない。
  • 刃物台の旋回径：タレットが回るとき、いちばん外に出ている工具の先が描く円。この円がチャックの爪・ワーク・心押台と重なると、工具を割り出した瞬間に衝突する。長いボーリングバーや大きなドリルを付けたときに特に危ない。
  • 工具の突出し制限：ツーリング図には、ステーションごとに工具を突き出せる長さの上限が描かれている。隣の工具や反対側の刃物台とぶつからない範囲である。
  • Z方向：チャックの端面から刃物台までの距離で、加工できる長さと、長い工具を使ったときにチャックに近づける限界が決まる。

現場でよくある失敗カタログの最大加工径だけを見て決め、実際には爪の高さと内径用の工具の突出しで旋回径がぶつかる。打ち合わせでは「一番大きなワーク」「一番長い工具」「爪の形」を干渉図の上に描き込んで確かめる。

マシニングセンタの動作範囲図の読み方

立形マシニングセンタで一番見落とされやすいのが、主軸端からテーブル上面までの距離である。Z軸のストロークが500mmあっても、治具・ワーク・工具の長さを足すと、上下どちらかで足りなくなることがある。次の2つの条件を両方満たす必要がある。

上の条件：治具の高さ ＋ ワークの高さ ＋ 工具長 ＋ 逃がす余裕 ≦ 主軸端〜テーブル（最大）下の条件：治具の高さ ＋ ワークの高さ − 加工の深さ ＋ 工具長 ≧ 主軸端〜テーブル（最小）

自分の値を入れて確かめられる。初期値は、よくある立形マシニングセンタの例である。

—工具がワークの上に逃げたときの主軸端の高さ
—いちばん深く削るときの主軸端の高さ

そのほかに見るところ

項目見るポイント
テーブルの大きさと積載質量ワーク＋治具が載るか。偏った重さでも許されるか
X・Y軸のストロークテーブルの大きさより小さいことが多い。ワークの端の穴まで主軸が届くか
ATCの工具の最大径・長さ・質量隣の工具を空けたときの最大径の条件も確認する
ATC位置（工具交換のときの主軸の高さ）工具交換でZ軸が上がる位置で、長い工具が治具やワークに当たらないか
扉の開口と吊り込みクレーンでワークを入れるなら、扉の開口の幅と上方向の開き
ロータリテーブルの干渉円（第4軸・5軸）回したときにワークや治具の角が描く円が、機械のカバーや主軸頭に当たらないか

5軸・複合加工機はさらに慎重に

回転軸がある機械では、傾けたときに主軸頭や治具が当たる範囲が、角度によって変わる。カタログの図は代表的な姿勢だけを描いていることが多いため、機械の3Dモデルを使ったシミュレーションで確かめるのが確実である。5軸マシニングセンタや複合加工機の打ち合わせでは、メーカーに機械モデルの提供を依頼しておく。

営業の現場から干渉は、機械が届いてから見つかると取り返しがつかない。発注前に「一番大きなワーク」「一番長い工具」「治具の外形」の3つをメーカーに渡し、干渉チェックの図を出してもらうのが、もっとも安い保険である。
