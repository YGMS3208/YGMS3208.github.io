汎用工作機械とNC工作機械の違い

汎用工作機械とNC工作機械の違いは、機械の動かし方にある。汎用機は作業者がハンドルを回して工具を送り、NC工作機械はプログラムの数値に従ってサーボモータが軸を動かす。同じ形の繰返しや複雑な形にはNC機、単品の修理や簡単な加工には汎用機が向く。

動かし方の違い

汎用工作機械は、作業者がハンドルを回して工具やテーブルを動かす。送った量は、ハンドルの目盛りや、移動量を数字で表示する装置で確かめる。どこを、どの順で、どの速さで削るかは、すべて作業者が判断する。

NC工作機械は、加工の手順を数値で書いたプログラム（NCプログラム）をNC装置に読み込ませて動かす。NC装置は各軸のサーボモータに指令を送り、ボールねじなどを介してテーブルや主軸を目標の位置へ動かす。位置は検出器で常に測られ、指令とのずれがあれば修正される。現在のNC装置はコンピュータを内蔵しており、CNC（コンピュータ数値制御）と呼ぶこともあるが、一般にはNCとまとめて呼ばれる。数値制御の工作機械は1950年代に生まれ、日本では1970年代以降に広く普及した。

NCで何ができるようになったか

NC化の大きな効果の1つは、2つ以上の軸を同時に動かして、斜めの線や円弧をなめらかに削れるようになったことである。これを補間という。汎用機で円弧や曲面を正確に削るには、高い技能や専用の工具・型が必要だった。

もう1つの効果は再現性である。一度正しいプログラムを作れば、何個目のワーク（工作物）でも同じ動きで加工できる。作業者の熟練度による差が小さくなり、1人で複数台の機械を受け持つこともできる。さらに、ATCやパレットチェンジャ、ロボットと組み合わせると、人がいない夜間にも加工を続けられる。自動車部品の量産ラインは、NC工作機械と自動化装置の組合せで成り立っている。

汎用機が今も使われる理由

汎用機は、図面を見てすぐに削り始められる。1個だけの修理部品や治具の追加工では、プログラムを作って確認するよりも早く終わることがある。機械の価格が比較的安く、構造が単純で保守もしやすい。

また、汎用機の操作は、切削の基本を体で覚えるのに向いている。工具の切れ味、切込みの深さ、送りの速さが、加工面や音にどう表れるかを直接感じられるため、教育の場で今も使われている。NC機を使う場合でも、この感覚は切削条件の設定やトラブルの判断に役立つ。

NC工作機械を使うために必要なこと

NC工作機械を使うには、プログラムを作る仕事が加わる。単純な形なら機械の画面で対話しながら作れるが、複雑な形ではCAM（コンピュータで工具経路を作るソフト）を使うことが多い。作ったプログラムは、画面上の描画や、ワークを削らずに動かす空運転で確かめてから実際に削る。

工具の長さや刃先の位置、ワークの原点をNC装置に正しく登録することも欠かせない。この設定を誤ると、工具がワークや治具に衝突するおそれがある。加工中は、工具の摩耗に合わせて補正値を調整し、寸法を管理する。汎用機では作業者の手が担っていた判断を、事前の準備と数値の管理に置き換えるのがNC工作機械の使い方である。

選び分けの目安

  • 同じ部品を繰り返し作るなら、NC工作機械が基本である。
  • 円弧、テーパ、曲面など、2軸以上を同時に動かす形状にはNC機が必要である。
  • 単品の修理や簡単な追加工が中心なら、汎用機の方が早く安く済むことがある。
  • 夜間の無人運転や自動化を考えるなら、NC機を前提にする。
  • NC機を導入するときは、プログラムの作成と確認ができる人材の育成も計画する。
  • 新人教育では、汎用機で切削の基本を学ぶことにも意味がある。
