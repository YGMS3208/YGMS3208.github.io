工作機械の安全：運転モード・インターロック・法令と規格

工作機械の事故は、段取り中と、安全装置を外したときに起きる。リスクアセスメントの考え方、運転モードと扉の関係、インターロックの種類、機能安全、ロボットセル、研削盤とレーザの決まり、輸出管理と海外の規格まで、機械を使う人・買う人・つくる人が知っておくことをまとめる。

このページについて法令と規格の要点を、工作機械の現場で使う順にまとめた。法令・規格は改正されるため、実際の設計・運用では、原文と最新版で確かめること。

法令と規格の体系

  • 労働安全衛生法：事業者に、機械の危険を調べて減らすこと（リスクアセスメント）を努力義務として求めている。機械をつくる側・使う側それぞれの進め方は、厚生労働省の「機械の包括的な安全基準に関する指針」に示されている。機械を譲渡・貸与する者は、残っている危険（残留リスク）などの情報を使う側に通知する。
  • 国際規格の階層：すべての機械に共通の基本規格（A規格、ISO 12100）、安全装置などの共通規格（B規格、ISO 13849-1、ISO 14119、IEC 60204-1 など）、機種ごとの個別規格（C規格）がある。工作機械のC規格には、マシニングセンタなどの ISO 16090-1、旋盤の ISO 23125、研削盤の ISO 16089 がある。日本ではJIS B 9700 系として取り込まれているものが多い。

リスクアセスメントの3ステップ

  1. 本質安全設計：危険そのものをなくす・小さくする。挟まれない隙間、速度と力の制限、角の丸め。
  2. 安全防護：ガード（扉・カバー）、インターロック、光線式の安全装置、両手操作、イネーブルスイッチ。
  3. 使用上の情報：残った危険を、表示・警告・取扱説明書・教育で伝える。

この順番が大切で、表示や教育で済ませる前に、設計と防護で減らせないかを考える。メーカーは①〜③を行って残留リスクを伝え、使う側はそれを受けて作業手順・教育・保護具で対策する。

運転モードと扉

ISO 16090-1（マシニングセンタなど）と ISO 23125（旋盤）では、運転モードごとに、扉を開けたときに許される動きが決まっている。考え方は次のとおり（具体的な速度の上限などは規格本文で確かめる）。

モード扉許される動き操作
自動運転閉じて施錠すべての動きプログラムで運転
段取り・手動開けてよい制限した低い速度の軸移動、制限した主軸回転押している間だけ動く（ホールドツーラン）、イネーブルスイッチを併用
特別モード（加工の確かめ）開けてよい（条件付き）段取りより広い範囲。熟練者に限る鍵などで選択を管理、イネーブルスイッチ
保全モード開けてよい保全に必要な限られた動き管理者が選択

「段取りで扉を開け閉めするのが面倒だから、インターロックを外す」は、事故の典型である。扉を開けて作業する必要があるなら、正規の段取りモードを使う。モードの選択は鍵などで管理し、解除キーを誰でも使える所に置かない。

ガードとインターロック

  • 施錠式インターロック：主軸や砥石のように、止めてもすぐには止まらない（惰性で回る）機械では、扉を開けたら止まるだけでは足りない。止まりきるまで扉を開けられないよう施錠する。
  • 無効化の防止：インターロックのスイッチは、テープや予備のアクチュエータで簡単にだませない形式と取り付け方にする（ISO 14119）。だます必要があるほど作業がしにくいなら、作業手順か機械の設計を見直す。
  • 窓：扉の窓は、チャックの爪や工具の破片が飛んでも破れない強さが要る。ポリカーボネートの窓はクーラントや油で劣化して強さが落ちるため、決めた周期で交換する。
  • チャックの爪の飛散：高い回転では遠心力で把握力が下がる。チャックの許容回転数と、プログラムの最高回転数の制限を必ず守る。

機能安全：安全装置の信頼性

  • 安全に関わる制御（扉の監視、非常停止、速度の監視）は、壊れても危険側にならない設計が要る。その信頼性を表すのが、ISO 13849-1 のパフォーマンスレベル（PL a〜e）や IEC 62061 の SIL である。
  • 止め方には、すぐに動力を切る（停止カテゴリ0）、制御して止めてから動力を切る（カテゴリ1）、制御して止めて動力は残す（カテゴリ2）がある（IEC 60204-1）。
  • 安全PLCや、NC装置の安全機能（安全速度の監視など）を使うことが多い。
  • 衝突防止機能は人の安全機能ではない：機械どうしの衝突を3Dモデルで予測して止める機能は、機械を守るためのもので、モデルが実物と違えば検知できない。人を守る機能として扱わない。

ロボットセル

  • 産業用ロボットの安全規格は ISO 10218 で、協働ロボットの要求も含めて改訂が進んでいる。
  • 柵の高さと、危険な所までの距離は ISO 13857 に、光線式の安全装置と止まるまでの時間から決める距離は ISO 13855 に従う。
  • 日本では、定格出力80Wを超えるロボットの可動範囲内での教示などの作業には、特別教育が要る。
  • ワークの出し入れの窓、段取りのための入口、ロボットと工作機械のインタロック信号を、セル全体で設計する（ロボットによるワーク着脱）。

研削盤・レーザ加工機の決まり

  • 研削盤：砥石は最高使用周速度を超えて使わない。砥石を取り替えたときは3分以上、その日の作業を始める前は1分以上の試運転を行う。砥石の取替えと試運転の業務には特別教育が要る。砥石カバーを外して使わない。
  • レーザ加工機：レーザ製品はクラスで区分される（JIS C 6802）。高出力のレーザを扱う事業場には、厚生労働省の通達でレーザ光線による障害を防ぐための管理（管理者の選任、管理区域、保護具など）が求められている。加工中のヒュームの排気と火災にも備える。

輸出管理

  • 高精度の工作機械は、兵器の製造に使われうるため、外為法で輸出が規制されている。リスト規制では、位置決め精度や同時に制御できる軸の数などの性能が基準以上の機械は、輸出に経済産業大臣の許可が要る。
  • 基準未満でも、輸出先での用途や需要者によって許可が要るキャッチオール規制がある。
  • メーカーは機種ごとに該当・非該当を判定した該非判定書を出す。無断で移設されたことを検知して動かなくする移設検知装置を備えた機種も多い。
  • 中古機の輸出や、海外工場への移設でも同じ規制がかかる。

海外の規格

  • EU：機械にはCEマーキングが要る。現行の機械指令に代わる機械規則（EU）2023/1230が、2027年1月から適用される。電気装置は EN 60204-1。
  • 北米：電気は NFPA 79、部品は UL の認証が求められることが多い。電源の電圧と周波数も国ごとに違う。
  • サイバーセキュリティ：工場のネットワークにつながる工作機械が増え、NC装置の脆弱性への対応や、メーカーのセキュリティ窓口（PSIRT）の有無も、選定の確認項目になってきている。
