USED & RETROFIT

中古機・レトロフィットの見方

中古の工作機械は、新品の半値以下で手に入ることもあるが、見えない所に費用が隠れている。年式とNC装置の保守、主軸・送り軸・摺動面の状態、立会いでの確かめ方、レトロフィットとオーバーホールの選び方、法令と搬出入まで、買う前に見るところをまとめる。

中古機を選ぶ理由と、隠れた費用

中古機を選ぶ理由は、価格と納期である。新品は受注から納入まで数か月から1年以上かかることがあるが、中古機ならすぐに手に入る。一方で、本体価格のほかに、搬出・輸送・据付け・精度出し、消耗部品の交換、場合によってはオーバーホールやNCの換装がかかる。本体価格だけでなく、使える状態にするまでの総額と、あと何年使えるかで比べる。

費用中身見落としやすい点
本体機械本体と付属品工具・ホルダ・治具・チャックの爪が付くか
搬出・輸送解体、吊り出し、輸送、保険売り手の工場の搬出経路、重量物の運搬業者
据付け基礎、アンカー、レベル出し、電源・エア機械の重さと精度に合った基礎が今の工場にあるか
整備消耗部品の交換、油の入れ替え、清掃ワイパー、ベルト、フィルタ、電池、パッキン
修理・改造オーバーホール、NCの換装、安全装置の追加見積りは状態を見てからでないと出ない
立上げ精度の確認、試し加工、教育取扱説明書・図面がないと時間がかかる

見るところ

部位確かめ方注意するサイン
年式・NC装置銘板、NC装置の型式、サーボ・主軸アンプの型式メーカーの保守（部品供給）が終わっている、または近い。終わっていれば故障したときに直せない
主軸回転数を段階的に上げて、音・振動・温度を見る。テストバーで振れを測る特定の回転数での異音、温度が上がり続ける、振れが規定値を超える、工具の把持力が弱い
送り軸ボールバー、ダイヤルゲージでバックラッシ、早送りの音反転時の段差が大きい、ピッチ誤差・バックラッシの補正量がとても大きい（摩耗を補正で隠している）
摺動面・案内カバーを開けて目で見る、手で送ってがたを見るすべり面のきさげの模様が消えている、かじりの傷、リニアガイドのがた・さび
主軸テーパ・ATCテーパの当たり、ATCを繰り返し動かすテーパの傷・フレッティング、工具交換の失敗
油圧・潤滑・クーラント漏れ、ポンプの音、油の色、タンクの底作動油の白濁や黒ずみ、潤滑の配管の詰まり、タンクの底のスラッジ
電気盤の中、配線、ケーブル焦げ跡、改造の跡、図面と違う配線、ケーブルの被覆の割れ
外観と構造ベッド・コラムのき裂、補修溶接の跡衝突や落下の跡。ベッドのき裂は直せない
書類取扱説明書、電気図、ラダー、パラメータのバックアップ、精度検査表バックアップがないと、NCの電池切れや故障で動かせなくなる

立会いで確かめる方法

  1. 電源を入れて暖機する：冷えた状態の音と、暖まった後の音・温度の変化を比べる。
  2. アラーム履歴を見る：NCの画面で、過去のアラームの種類と頻度を見る。同じアラームが繰り返していないか。
  3. 主軸を全回転数域で回す：低速から最高回転数まで段階的に。異音と振動の出る回転数を記録する。
  4. ボールバーと位置決め：可能なら測定業者に依頼してボールバーを測る。円の形で、バックラッシや摩擦の状態がわかる（円の読み方）。
  5. 試し加工：自社の部品か、それに近い形を削って、寸法・面粗さ・びびりを見る。
  6. 補正量を見る：ピッチ誤差・バックラッシの補正値が極端に大きければ、ねじや軸受の摩耗が進んでいる。

レトロフィットとオーバーホール

方法中身向いている場合
整備（リフレッシュ）消耗部品の交換、油の入れ替え、調整状態は良く、消耗品だけ古い
オーバーホール主軸の軸受交換、ボールねじ・案内面の交換や再きさげ、精度の出し直し本体（ベッド・コラム）は健全だが、動く部分が摩耗している
レトロフィット（NCの換装）NC装置・サーボ・主軸のアンプとモータを新しい世代に替える機械は丈夫だが、NCの保守が終わった。大型機・特殊機で、新品が高価なもの
買い替え—本体にき裂・大きな変形がある、改造費が新品に近い

レトロフィットでは、NCを替えると、ラダー（機械の動作の順番の制御）とパラメータをつくり直すことになる。元の機械メーカーの協力が得られるか、改造業者に同じ機種の実績があるかを確かめる。改造後は、精度と安全機能を確かめ直す。

法令と安全

  • 輸出：中古機を海外に出すときも、外為法の規制がかかる。位置決め精度などが基準以上の機械は、輸出の許可が要る。メーカーに該非判定を依頼する（輸出管理）。
  • 移設検知装置：一部の機械には、無断の移設を検知すると動かなくなる装置がある。移設の前にメーカーに連絡し、手続きをとる。
  • 古い機械の安全：扉のインターロックや施錠式の扉がない、窓が劣化している、非常停止が足りない、など今の基準に合わないことがある。リスクアセスメントをして、使う前に対策する（工作機械の安全）。
  • 譲渡するとき：機械を譲渡する側は、残っている危険などの情報を相手に伝える。

最後は実物を見る写真と仕様書だけで決めず、必ず現物を見て、電源を入れて動かす。立会いに保全の担当者を連れて行くと、見落としが減る。
