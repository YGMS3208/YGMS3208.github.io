精度検査の読み方：位置決め精度・ボールバー・熱変位・不確かさ

カタログの位置決め精度はどう測った値か。ボールバーの円の形から何がわかるか。熱変位はどう試験するか。測った値の合否はどう判定するか。工作機械の精度を、検査の方法と数字の意味から読み解く。

精度の基本的な見方（幾何精度・位置決め精度・加工精度の違い）は工作機械の精度の見方で説明した。ここでは、検査の方法と、出てきた数字の読み方に踏み込む。規格は改正されることがあるため、実際の検査では最新版の規格本文で確かめてほしい。

位置決め精度は「統計」で表す

国際規格 ISO 230-2（日本では JIS B 6190-2）では、軸のストロークに沿って目標位置を決め（1mあたり5点以上が目安）、各位置に両方向から5回ずつ動かして、止まった位置を測る。その値から次の量を計算する。

記号名前意味
E一方向の系統的な位置偏差平均のずれ。ピッチ誤差補正で直せる部分
R↑・R↓一方向の繰返し性同じ向きで止めたときのばらつき（標準偏差の4倍＝±2s）
R両方向の繰返し性向きを変えたときも含めたばらつき
B反転値行きと帰りの平均のずれ。バックラッシやねじれ
A両方向の位置決め精度平均のずれ＋ばらつき（±2s）を含めた、ストローク全体の幅
M平均の両方向位置偏差ばらつきを含めない平均値の幅

カタログの「位置決め精度」は、どの規格のどの値かで数字が大きく変わる。日本で以前使われていた JIS B 6336（1986）の方式は、ばらつきを含めない値だったため、同じ機械でも ISO 230-2 の A より小さく見える。比べるときは、規格と値の種類をそろえる。量産の寸法ばらつきに効くのは繰返し性 R で、補正では直せない。

位置決め精度の値は輸出管理の判定にも使われる（外為法のリスト規制）。詳しくは安全・規格のガイドに書いた。

ボールバー：円の形で誤差を見分ける

ボールバー（DBB）は、両端に球の付いた伸縮する棒を主軸とテーブルの間に付け、機械に円を描かせて半径の変化を測る。数分で、2軸の誤差の「くせ」がわかる。下のスライダで誤差を足すと、円の形がどう変わるかを確かめられる（ずれは拡大している）。

  • 測定は、半径100〜150mm程度で、時計回りと反時計回りの両方、XY・YZ・ZXの3平面で行う。
  • 送り速度を変えて2回測る：形が変わらない誤差は機械の幾何（直角度・スケール）、送り速度で変わる誤差はサーボ（追従の遅れ、反転時の補正）による。
  • 反転時の突起（象限突起）は反転時の摩擦とロストモーション、斜め45°の楕円は直角度（回る向きを変えても同じ）かサーボゲインの不一致（向きで傾きが逆）、と覚えておく。

レーザ干渉計で測るときの誤差

位置決め精度の測定には、主にレーザ干渉計を使う。測定器そのものは高精度でも、置き方と環境で誤差が入る。

誤差原因対策
アッベ誤差測る軸と、実際に加工する点（工具の先）が離れていて、軸の傾きがずれとして入る反射鏡をできるだけ工具の先の高さ・位置に置く
コサイン誤差レーザ光と軸の向きがずれている光軸を軸に平行に合わせる（ずれ1mrad で 0.5ppm）
デッドパス干渉計と反射鏡の間の、測らない区間の空気の変化干渉計を反射鏡にできるだけ近づける
空気の状態レーザの波長は空気の温度・気圧・湿度で変わる環境センサで補正（空気1℃で約1ppm、気圧約3.6hPaで約1ppm）
材料の温度機械のスケールや工作物が伸び縮みする材料温度センサで20℃に換算（鋼は1℃で約11.5ppm）

直進する軸1本には、送り方向の位置のほか、2方向の真直度、3方向の傾き（ピッチ・ヨー・ロール）の合計6つの誤差がある。3軸の機械では、これに軸どうしの直角度3つを加えた21項目が幾何誤差の全体になる。

熱変形の試験

熱による変位は、量産で寸法がずれる最大の原因の一つである（仕組みと対策は熱変位、数字の見積りは剛性・熱変位のガイド）。試験の方法は ISO 230-3（JIS B 6190-3）に示されている。

  • 環境温度の変化による誤差（ETVE）：機械を止めたまま、室温の1日の変化で主軸と工作物の相対位置がどれだけ動くかを測る。
  • 主軸の回転による変位：テストマンドレルを主軸に付け、回転数を決めて回し続け、変位センサで5方向（X・Y・Z と2方向の傾き）を時間とともに測る。
  • 送り軸を動かしたときのドリフト：軸を往復させ続けて、位置の変化を測る。

測定の基準温度は20℃。部品も測定器も、測る前に同じ温度になじませる（小物で1時間以上、大物はもっと長く）。

5軸機の回転軸の精度

  • 回転軸の幾何誤差：回転中心の位置のずれ、回転軸と直進軸の直角度・平行度など。この誤差は、工具の先端位置を計算する工具先端点制御（TCP）の精度にそのまま効く。
  • 測り方：基準球（キャリブレーション球）をテーブルに置き、タッチプローブで回転軸を回しながら球の中心を測る。多くの機種に、機上で自動測定して補正する機能がある。Rテスト（ISO 10791-6）は、球の位置を変位センサで追う方法。
  • 加工で確かめる：ISO 10791-7 には5軸の加工試験片が示されている。昔から使われてきた円錐台の試験片（NAS 979）と目的が違うので、どの試験で評価するかを契約で決める。

主軸の回転精度

テストバーを付けてダイヤルゲージで見る「振れ」には、バー自体の偏心や取付けの誤差が混ざる。主軸そのものの回転の誤差（回転誤差運動、ISO 230-7）は、回転に同期した成分（毎回同じ形）と、同期しない成分（毎回違う）に分けて考える。同期成分は加工した穴や軸の真円度に、非同期成分は面粗さに効く。振れは主軸端と、300mm先の両方で測り、差から傾きを読む。

測った値の合否をどう判定するか

立会いや受入れで「メーカーの成績書と値が合わない」ことは珍しくない。原因の多くは、測定の不確かさ（測定器・温度・測り方・人による幅）である。

  • 判定の考え方：ISO 14253-1 では、合格を証明するには、公差の両端から不確かさの分だけ内側に入っていることを求める。ぎりぎりの値は、測る側によって合否が分かれる。
  • 測定器の選び方：公差に対して不確かさが1/4以下、できれば1/10以下になる測定器と方法を選ぶ。
  • ゲージR&R：測定のばらつき（繰返し性と人による再現性）が公差の10%以下なら良好、30%を超えると使えないとされることが多い。
  • 成績書に書くこと：測定器と校正の日付、測定時の温度、測定方法と規格、測定点。これがそろっていれば、値が合わないときに原因を追える。
  • 機上計測の落とし穴：同じ機械で削って同じ機械で測ると、機械に共通の誤差は打ち消されて見えない。定期的に機外の測定機で確かめる。
